강의 전 사전 준비 안내

2차 실습 1막 · 기획 — 시작 전 20분만 투자하면 됩니다

대상: VS Code와 Claude Code(또는 OpenAI Codex)를 이미 쓰고 있는 기자
소요 시간: 약 20분 (네이버 계정이 있으면 15분)
왜 미리 하나: 강의 2시간 중 세팅에 시간을 쓰면 정작 중요한 질문 목록 만들기를 못 합니다
마감: 강의 전날까지. 막히면 미리 알려 주세요

한눈에 보는 준비물

  • 노트북 (Windows 또는 macOS) · 인터넷
  • 파이썬 3.11 이상 설치 — 이미 있으면 확인만
  • VS Code — 이미 쓰고 계시면 그대로
  • Claude Code 또는 OpenAI Codex — 둘 중 하나만. 로그인까지 되어 있을 것
  • 네이버 검색 API 키 (Client ID / Client Secret) — 아래 2번
  • 스타터 파일 압축 풀고 세팅 — 아래 3~4번
  • 최종 동작 확인 문구 준비 완료 를 봤을 것 — 아래 5번

DART·국회 API 키는 이번에 필요 없습니다. 1막(기획)은 네이버 키 하나만 씁니다. DART·국회 키는 다음 회차(2막·취재)에서 안내드립니다.

1파이썬 확인2분

VS Code에서 터미널을 엽니다. Terminal > New Terminal (단축키 Ctrl + 백틱 `)

python --version

Python 3.11.x 처럼 3.11 이상이 나오면 통과입니다. macOS는 python3 --version 으로 확인하세요.

버전이 안 나오거나 3.10 이하라면

  1. python.org 접속 → 상단 Downloads → 노란 버튼 클릭
  2. 설치 첫 화면에서 "Add python.exe to PATH" 를 반드시 체크 → Install Now
  3. 설치 후 VS Code를 껐다 다시 켜고 위 명령을 다시 실행

"Add to PATH" 를 빠뜨렸다면 — 터미널이 python 을 못 찾습니다. 설치 파일을 다시 실행해 Modify 에서 PATH를 추가하면 됩니다. 재설치할 필요 없습니다.

2네이버 검색 API 키 발급7분

과거 기사를 모으는 데 씁니다. 무료이고 즉시 발급됩니다. 심사·승인 대기가 없습니다.

2-1. 발급 절차

  1. developers.naver.com 접속 → 우측 상단에서 네이버 계정으로 로그인
    평소 쓰는 개인 네이버 계정이면 됩니다. 별도 개발자 가입 절차 없습니다.
  2. 상단 메뉴 Application → 애플리케이션 등록
  3. 애플리케이션 이름 입력 — 아무거나 괜찮습니다. 예: 취재실습
  4. 사용 API 에서 "검색" 을 선택
    이 단계를 빠뜨리면 나중에 401 오류가 납니다. 목록에서 '검색'을 꼭 고르세요.
  5. 비로그인 오픈 API 서비스 환경 에서 "WEB 설정" 선택 → 웹 서비스 URL 칸에 아래를 입력 
    http://localhost
    실제로 접속하는 주소가 아니라 형식상 필요한 값입니다. 그대로 넣으세요.
  6. 등록하기 클릭 → 다음 화면에 Client ID 와 Client Secret 이 나옵니다
  7. 두 값을 메모장에 복사해 두세요. 4번 단계에서 씁니다
    나중에 다시 볼 수 있습니다. Application > 내 애플리케이션 > 해당 앱

2-2. 자주 막히는 지점

상황대처
사용 API 목록에 '검색'이 안 보임 스크롤을 내려 보세요. 목록이 깁니다
등록 후 "검색 API를 추가하지 않았다"는 걸 알았음 지우고 다시 만들 필요 없음. 내 애플리케이션 > API 설정 에서 추가 가능
웹 서비스 URL 형식 오류 http://localhost 를 그대로. 끝에 슬래시(/)나 공백을 넣지 마세요
Client Secret이 가려져 보임 옆의 보기 버튼을 누르면 나옵니다

키는 비밀번호와 같습니다. 메신저·이메일로 공유하지 마세요. 강의 중에도 화면 공유 시 노출되지 않게 주의해 주세요. 실수로 노출됐다면 내 애플리케이션에서 재발급하면 됩니다.

3스타터 파일 받기2분

본인이 쓰는 도구에 맞는 것 하나만 받으세요. 두 개를 다 받을 필요 없습니다.

쓰는 도구내려받기
Claude Code starter-claude.zip 내려받기
OpenAI Codex starter-codex.zip 내려받기

다운로드가 안 되면 — 저장소에서 직접 받을 수도 있습니다. Claude용 · Codex용
브라우저가 zip을 열지 않고 그냥 보여준다면, 링크를 마우스 오른쪽 클릭 → 다른 이름으로 링크 저장 하세요.

압축을 풀면 newsroom_agent/ 폴더가 나옵니다.

  1. 이 폴더를 원하는 위치에 두세요. (예: C:\vscode\newsroom_agent)
    한글·공백이 없는 경로를 권합니다. 바탕화면·다운로드 폴더는 피하세요.
  2. VS Code에서 File > Open Folder → 이 newsroom_agent 폴더를 선택

이 폴더는 2·3막까지 계속 씁니다. 이름을 바꾸거나 지우지 마세요. 회차가 바뀌어도 같은 폴더에서 이어집니다.

4세팅5분

VS Code에서 newsroom_agent 폴더를 연 상태로, 터미널을 열고 순서대로 실행합니다.

① 가상환경 만들기 (한 번만)

# Windows
python -m venv .venv

# macOS
python3 -m venv .venv

② 활성화

# Windows · PowerShell
.venv\Scripts\Activate.ps1

# macOS
source .venv/bin/activate

입력줄 맨 앞에 (.venv) 가 붙으면 성공입니다.

(.venv) PS C:\vscode\newsroom_agent>
 ↑ 이 표시가 핵심

Windows에서 "이 시스템에서 스크립트를 실행할 수 없으므로…" 오류가 나면
아래를 한 번만 실행한 뒤 ② 를 다시 하세요. 보안상 안전한 표준 설정입니다.

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

③ 패키지 설치

(.venv) 가 켜진 상태에서:

pip install -r requirements.txt

④ API 키 넣기

먼저 서식 파일을 복사합니다.

# Windows PowerShell
Copy-Item .env.example .env

# macOS
cp .env.example .env

VS Code 왼쪽 탐색기에서 .env 파일을 열고, 2번에서 받은 키를 채웁니다.

NAVER_CLIENT_ID=여기에_발급받은_ID
NAVER_CLIENT_SECRET=여기에_발급받은_SECRET

이 세 가지만 지키면 됩니다.
· 등호(=) 앞뒤에 공백을 넣지 마세요
· 값 뒤에 주석을 붙이지 마세요 (예: NAVER_CLIENT_ID=abc123 # 내 키 ✗)
· 따옴표는 써도 되고 안 써도 됩니다

아래 DART_API_KEY, ASSEMBLY_API_KEY 는 비워 두세요. 2막에서 씁니다.

5최종 동작 확인2분

이 단계까지 통과해야 준비 완료입니다. (.venv) 가 켜진 상태에서 아래를 복사해 붙여넣으세요.

python -c "import os,requests,dotenv; dotenv.load_dotenv(); k=os.getenv('NAVER_CLIENT_ID'); print('준비 완료' if k and '여기에' not in k else '.env 의 키를 확인하세요')"

준비 완료 가 나오면 끝입니다. 강의 때 뵙겠습니다.

나온 결과의미와 대처
준비 완료 통과. 더 할 것 없습니다
.env 의 키를 확인하세요 .env 파일이 없거나 키를 안 채웠습니다. 4-④ 다시
ModuleNotFoundError (.venv) 가 안 켜진 상태입니다. 4-② 다시
python 을 찾을 수 없음 파이썬 미설치 또는 PATH 누락. 1번 다시

여기까지 됐으면 실제 수집도 됩니다. 궁금하시면 강의 전에 미리 돌려 보셔도 좋습니다. 다만 필수는 아닙니다.

# Claude Code용 스타터
python .claude/skills/background-collect/collect_news.py

# Codex용 스타터
python .agents/skills/background-collect/collect_news.py

검색어 3개로 800건 안팎이 모이고, 수집 기간과 매체 분포가 출력되면 정상입니다.

자주 묻는 질문

Claude Code와 Codex 중 뭘 써야 하나요?

이미 쓰고 계신 것을 쓰세요. 결과물에 큰 차이가 없고, 강의 자료에 양쪽 안내가 모두 들어 있습니다. 둘 다 있으면 Claude Code를 권합니다 — 자료가 조금 더 많습니다.

파이썬을 몰라도 되나요?

됩니다. 스타터에 스크립트가 이미 들어 있고, 강의에서는 검색어 몇 개를 바꾸는 것이 전부입니다. 코드를 읽거나 쓸 필요 없습니다.

회사 노트북이라 설치가 제한됩니다

미리 알려 주세요. 파이썬 설치가 막히면 관리자 권한 없이 쓰는 방법이 있습니다. 다만 사전에 확인이 필요합니다.

구글 Gemini를 쓰고 있는데요

2026년 6월 18일부로 Gemini CLI가 종료됐고 후속은 Antigravity CLI(agy)입니다. 다만 무료 사용량이 하루 20회 안팎으로 매우 빡빡해 실습 중 멈출 위험이 큽니다. 이번 실습은 Claude Code 또는 Codex로 진행해 주세요.

DART·국회 키도 지금 받아 둘까요?

받아 두셔도 좋지만 이번엔 필요 없습니다. 2막 안내 때 발급 절차를 따로 보내 드립니다. 그쪽은 회원가입·본인인증이 있어 시간이 더 걸립니다.

공통 주제 대신 제 출입처 주제를 써도 되나요?

됩니다. 다만 세 소스(뉴스·공시·의안)에서 같은 이름이 반복 등장하는 주제여야 뒤 회차의 교차검증이 굴러갑니다. 한 줄로 적어 오시면 강의 중에 함께 판단해 보겠습니다.
