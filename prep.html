  • 스타터 파일 내려받아 압축 풀기

1파이썬 확인2분

VS Code에서 터미널을 엽니다. Terminal > New Terminal (단축키 Ctrl + 백틱 `)

python --version

Python 3.11.x 처럼 3.11 이상이 나오면 통과입니다. macOS는 python3 --version 으로 확인하세요.

버전이 안 나오거나 3.10 이하라면

  1. python.org 접속 → 상단 Downloads → 노란 버튼 클릭
  2. 설치 첫 화면에서 "Add python.exe to PATH" 를 반드시 체크 → Install Now
  3. 설치 후 VS Code를 껐다 다시 켜고 위 명령을 다시 실행

"Add to PATH" 를 빠뜨렸다면 — 터미널이 python 을 못 찾습니다. 설치 파일을 다시 실행해 Modify 에서 PATH를 추가하면 됩니다. 재설치할 필요 없습니다.

3-1. 네이버 검색 API5분 · 가장 쉬움

과거 기사를 모으는 데 씁니다. 별도 가입 없이 평소 쓰는 네이버 계정으로 바로 됩니다.

  1. developers.naver.com 접속 → 우측 상단 네이버 계정으로 로그인
  2. 상단 메뉴 Application → 애플리케이션 등록
  3. 애플리케이션 이름 입력 — 아무거나 괜찮습니다. 예: 취재실습
  4. 사용 API 목록에서 "검색" 을 선택

    이 단계를 빠뜨리면 나중에 401 오류가 납니다. 목록이 기니까 스크롤을 내려 '검색'을 꼭 찾아 체크하세요. 실습에서 가장 흔한 사고 지점입니다.

  5. 비로그인 오픈 API 서비스 환경 에서 "WEB 설정" 을 고르고, 웹 서비스 URL 칸에 아래를 그대로 입력 
    http://localhost
    실제로 접속하는 주소가 아니라 형식상 필요한 값입니다. 끝에 슬래시(/)나 공백을 넣지 마세요.
  6. 등록하기 → 다음 화면에 Client ID 와 Client Secret 이 나옵니다
  7. 두 값을 메모장에 복사해 두세요
    Client Secret이 가려져 있으면 옆의 보기 버튼을 누르세요. 나중에 Application > 내 애플리케이션 에서 다시 볼 수 있습니다.

'검색' API 추가를 빠뜨렸다면 — 지우고 다시 만들 필요 없습니다. 내 애플리케이션 > API 설정 에서 추가하면 됩니다.

3-2. DART 전자공시7분

기업 공시를 받는 데 씁니다. 금융감독원이 운영합니다.

  1. opendart.fss.or.kr 접속
  2. 상단 메뉴 인증키 신청/관리 → 인증키 신청
  3. 사용자 구분 에서 반드시 "개인" 을 선택

    여기가 핵심입니다. "기업"을 선택하면 사업자등록증 첨부가 필요하고 관리자 승인에 1~2 영업일이 걸립니다. "개인"은 즉시 발급됩니다. 회사 업무용이라도 개인으로 신청하세요.

  4. 입력 항목
    항목입력할 내용
    이메일받으실 메일 주소. 여기로 인증키가 발송되니 정확히
    비밀번호영문 + 숫자 + 특수문자 조합, 8~14자 (조건이 까다로우니 미리 정해두세요)
    비밀번호 확인위와 동일하게
    API 사용환경웹 선택
    API 사용용도예: 취재 데이터 분석 교육 실습
    확인 URLhttp://localhost
  5. 신청 완료 → 등록한 이메일로 인증키가 발송됩니다. 개인은 즉시 발송됩니다
  6. 메일에서 40자리 영문·숫자 조합의 키를 복사해 메모장에 저장
    메일이 안 오면 스팸함을 확인하세요. 로그인 후 마이페이지 에서도 확인할 수 있습니다.

3-3. 열린국회정보7분

법안(의안)과 발의 의원 명단을 받는 데 씁니다.

  1. open.assembly.go.kr 접속
  2. 회원가입 후 로그인

    국회 통합 로그인을 씁니다. 국회 다른 사이트(의안정보시스템 등) 계정이 이미 있으면 그 계정으로 바로 로그인하시면 됩니다. 없으면 가입 후 진행하세요.

  3. 로그인한 상태에서 OPEN API 메뉴로 이동
    화면 구성이 바뀌었으면 '인증키' 라는 단어를 찾으세요. 아래 주소로 바로 가셔도 됩니다. 
    open.assembly.go.kr/portal/openapi/main.do
  4. 인증키 신청 → 승인 절차 없이 즉시 발급됩니다
  5. 발급된 키를 메모장에 복사
    로그인만 하면 마이페이지 에서 언제든 다시 확인할 수 있습니다.

로그인이 풀린 채로는 인증키 페이지가 열리지 않습니다. 클릭했는데 로그인 화면으로 튕기면 정상입니다. 로그인 후 다시 들어가세요.

3-4. 키 보관 방법

메모장이나 노트 앱에 이름을 붙여서 정리해 두세요. 강의 당일 .env 파일에 붙여넣습니다.

NAVER_CLIENT_ID       = (네이버에서 받은 Client ID)
NAVER_CLIENT_SECRET   = (네이버에서 받은 Client Secret)
DART_API_KEY          = (DART 메일로 받은 40자리)
ASSEMBLY_API_KEY      = (국회에서 받은 인증키)

키는 비밀번호와 같습니다.
· 메신저·이메일·SNS로 공유하지 마세요
· 화면 공유·발표 때 노출되지 않게 주의해 주세요
· 실수로 노출됐다면 각 사이트에서 재발급받으면 됩니다 (무료·즉시)

4강의 당일에 할 것미리 안 하셔도 됩니다

이 절은 읽어만 두세요. 강의 시작 15분 동안 다 같이 진행합니다. 미리 해 오셔도 좋지만 필수가 아닙니다. 무엇을 하게 되는지만 알아두시면 됩니다.

  1. 스타터 파일 내려받기 — 쓰시는 도구에 맞는 것 하나만
    쓰는 도구내려받기
    Claude Code starter-claude.zip
    OpenAI Codex starter-codex.zip
    압축을 풀면 newsroom_agent/ 폴더가 나옵니다. VS Code에서 이 폴더를 엽니다.
  2. 가상환경 만들고 패키지 설치 
    python -m venv .venv
    활성화 명령은 터미널 종류에 따라 다릅니다. 
    # Windows · PowerShell  (VS Code 기본. 앞에 PS 가 보임)
.venv\Scripts\Activate.ps1

# Windows · 명령 프롬프트(cmd)  (앞에 C:\... > 만 보임)
.venv\Scripts\activate.bat

# macOS / Linux
source .venv/bin/activate
    입력줄 앞에 (.venv) 가 붙으면 성공입니다. 그다음: 
    pip install -r requirements.txt

    PowerShell에서 "이 시스템에서 스크립트를 실행할 수 없으므로…" 오류가 나면
    가장 간단한 해결은 activate.bat 을 쓰는 것입니다. 이 방식은 실행정책 제한을 받지 않습니다.

    .venv\Scripts\activate.bat

    PowerShell을 계속 쓰고 싶으시면 아래를 한 번만 실행한 뒤 다시 활성화하세요.

    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  3. 받아 오신 키를 .env 에 붙여넣기 
    Copy-Item .env.example .env       # macOS: cp .env.example .env
  4. 동작 확인 후 바로 실습 시작

미리 해 두고 싶으시면 — 스타터 안의 README.md 에 같은 내용이 단계별로 적혀 있습니다. 다만 Windows에서 가상환경 활성화가 막히는 경우가 있어(실행정책 문제), 혼자 하시다 막히면 그냥 두고 오셔도 됩니다. 당일 함께 해결합니다.

자주 묻는 질문

Claude Code와 Codex 중 뭘 써야 하나요?

이미 쓰고 계신 것을 쓰세요. 둘 다 없으시면 Claude Code를 권합니다 — 강의 자료가 이 도구 기준으로 작성돼 있어 화면이 그대로 일치합니다. Codex를 쓰셔도 각 문서 마지막의 "Codex로 만들기" 절만 따라오시면 됩니다.

키 3개를 다 받아야 하나요?

네. 실습의 핵심이 같은 사안을 세 소스로 교차검증하는 것이라, 하나만 있으면 그 대목을 못 합니다. 다만 네이버 하나만 있어도 첫 회차는 따라올 수 있으니, 나머지가 막히셔도 일단 오세요.

파이썬을 몰라도 되나요?
